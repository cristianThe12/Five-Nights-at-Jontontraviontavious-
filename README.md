# Five-Nights-at-Jontontraviontavious-
My first ever game. Uses Java swing to render images to the screen and appends text to display information such as maps and keybinds. Has seven nights of increasing difficulty where the player must protects themselves from several dangerous entities. The seventh night allows the user to customize the entities AI values and change the difficulty.
because this was my first every game project, I had AI help out with implementations of Java swing, as I had no clue what I was doing.
Many things are very sloppy due to it being my first time, but it was a learning experience that allowed me to get much better at coding and game development.
